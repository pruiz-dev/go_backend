# Global Assistant Instructions

## 1. Repository Architecture (Разделение кода и учёбы)
Репозиторий строго разделён на две зоны:
- `subtracker/` — чистый Go-проект для портфолио. ЗАПРЕЩЕНО класть сюда учебные конспекты, файлы `THEORY.md`, `PLAN.md` или черновые упражнения.
- `learning/` — вся учебная инфраструктура:
  - `learning/tickets/` — теория и описания рабочих тикетов по модулям (создаются через `/lesson`).
  - `learning/drills/` — короткие изолированные тренажёры и задачи с собеседований (создаются через `/practice`).
  - `learning/knowledge_base/` — лаконичные шпаргалки для подготовки к собеседованиям (создаются через `/kb`).

## 2. Session Startup & State Protocol (Защита от потери контекста)
Перед выполнением ЛЮБОЙ команды (`/lesson`, `/practice`, `/review`, `/quiz`, `/kb`) или ответа на рабочий вопрос:
1. Всегда сначала прочитай `PROGRESS.md` и `CURRICULUM_V2.md` в корне репозитория.
2. Опирайся на `PROGRESS.md` как на единственный источник истины о текущем тикете, статусе задач и слабых местах пользователя.
3. После выдачи нового тикета (`/lesson`), завершения проверки (`/review`) или выявления пробелов на `/quiz` — **обязательно обновляй `PROGRESS.md`**.
4. Когда все тикеты текущего модуля закрыты — отмечай модуль `[x]` в `CURRICULUM_V2.md`.

## 3. Strict Formatting Directive: Absolute Ban on Dollar Signs ($) and LaTeX
В чате с пользователем и во всех создаваемых markdown-файлах:
1. **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО использовать символ доллара `$`** для математики, переменных, формул или стрелочек.
2. Чат не рендерит LaTeX и превращает его в нечитаемый мусор.
3. **Стрелочки:** писать ТОЛЬКО обычным текстом `->` или символом Unicode `→`.
4. **Переменные и формулы:** писать ТОЛЬКО обычным текстом: `N = 50 000`, `N * (N + 1) / 2`, `O(N)`, `O(N^2)`.
5. Единственное исключение, где символ `$` разрешен — это синтаксис bash/терминала (`$ go run`) или денежные строки внутри кода на Go (`"$100"`).
