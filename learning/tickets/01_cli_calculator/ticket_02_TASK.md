# Тикет 02: Периоды оплаты и проверка условий (`if`, `switch`)

## Контекст
Реальные подписки списываются не только раз в месяц. Например, домен или IDE оплачиваются раз в год (`"yearly"`), облачный сервис — раз в неделю (`"weekly"`), а какая-то подписка может быть временно поставлена на паузу (`isActive == false`). Кроме того, бэкенд всегда должен защищаться от некорректных входных данных (отрицательная цена или неизвестный период).

## Что нужно сделать
1. В `subtracker/main.go` добавь поддержку периодов оплаты: `"monthly"`, `"yearly"`, `"weekly"`.
2. Реализуй функцию (или обнови существующую логику расчёта), которая по цене за период, названию периода (`string`) и статусу активности (`bool`) рассчитывает **стоимость в месяц** и **стоимость в год**:
   - Для `"monthly"`: в месяце 1 период, в году 12 месяцев.
   - Для `"yearly"`: месячный эквивалент — цена, делённая на `12`, годовой — сама цена.
   - Для `"weekly"`: для учебного расчёта считаем, что в году 52 недели (годовая = `cost * 52`, месячная = годовая / `12`).
   - Выбор формулы по периоду реализуй через `switch` с веткой `default`.
   - Подсказка: функция в Go может возвращать сразу несколько значений — например, `(float64, float64, bool)`, или можно сделать две понятные функции и отдельную функцию валидации. Выбери тот вариант, который проще читается.
3. Добавь проверки через `if` и логические операторы:
   - Если цена меньше нуля (`cost < 0`) или период не относится к `"monthly"`, `"yearly"`, `"weekly"` — выводи понятное сообщение об ошибке и не печатай ложный расчёт.
   - Если подписка неактивна (`!isActive`), её текущие траты в месяц и в год должны считаться как `0.00`.
4. Вынеси печать карточки/строки подписки в отдельную функцию и вызови её из `main()` минимум для 3–4 разных кейсов (например: активная `"monthly"`, активная `"yearly"`, неактивная подписка и кейс с некорректным периодом или отрицательной ценой), чтобы сразу увидеть работу всех веток.

## Критерии приёмки (Definition of Done)
- [ ] Команда `go run .` из `subtracker/` отрабатывает без ошибок и показывает расчёт для разных периодов оплаты и статусов активности.
- [ ] Для `"yearly"` и `"weekly"` корректно считаются и месячный, и годовой эквиваленты с двумя знаками после запятой.
- [ ] Неактивная подписка (`isActive == false`) даёт `0.00` в текущих тратах.
- [ ] Некорректная цена (`< 0`) или неизвестный период оплаты (например, `"daily"`) аккуратно обрабатываются и сообщают об ошибке в консоль.
- [ ] Для выбора периода используется `switch`, для проверок — `if` и логические операторы.
