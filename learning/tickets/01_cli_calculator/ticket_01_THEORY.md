# Теория к тикету 01: Модуль Go, переменные, типы и функции

## 1. Go-модуль и точка входа (`go.mod`, `package main`, `func main()`)
**Go-модуль (`go.mod`)** — это паспорт проекта, который лежит в корне кода и сообщает компилятору имя проекта и версию Go.
*Аналогия:* как техпаспорт квартиры или `package.json` в мире JavaScript — без него инструменты Go не понимают, где границы проекта. Создаётся одной командой `go mod init subtracker`.

**Пакет (`package`)** — это папка, объединяющая связанные файлы кода. В запускаемой программе главный файл всегда объявляется как `package main`, а внутри него обязана быть функция `func main()` — **точка входа**, с которой начинается выполнение программы.
*Аналогия:* `package main` — это главный цех завода, а `func main()` — кнопка «Пуск» на пульте.

## 2. Переменные и базовые типы
**Переменная** — это именованная коробка для хранения данных конкретного типа. В Go тип данных задаётся один раз и не меняется (статическая типизация), что спасает от глупых ошибок ещё до запуска программы.

Основные базовые типы, которые понадобятся сейчас:
- `string` — текст в двойных кавычках (`"Яндекс Плюс"`). Одинарные кавычки в Go для строк использовать нельзя.
- `int` — целое число (`12`, `365`, `-5`).
- `float64` — дробное число с точкой (`299.50`). Удобно для учебных расчётов; для реальных банковских денег в будущем познакомимся с копейками в `int64` или специальными библиотеками.
- `bool` — логический флаг: только `true` (истина) или `false` (ложь).

В Go есть два основных способа создать переменную:
```go
// 1. Короткое объявление (используется в 90% случаев внутри функций):
// Go сам понимает тип по значению справа.
cups := 3          // int
price := 180.5     // float64
drink := "Латте"   // string
isHot := true      // bool

// 2. Явное объявление через var (когда тип нужно указать вручную или значение будет задано позже):
var discount float64 = 0.1
```
Важная особенность Go: если объявить переменную и нигде её не использовать — код **не скомпилируется**. Компилятор следит за чистотой кода.

## 3. Функции и возврат значений
**Функция (`func`)** — это обособленный блок кода с именем, который принимает входные данные (параметры), выполняет расчёт и может вернуть результат.
*Аналогия:* соковыжималка — на вход даёшь апельсины (параметры с их типами), на выходе получаешь стакан сока (возвращаемое значение и его тип).

```go
// Принимает цену за штуку (float64) и количество (int), возвращает общую сумму (float64).
// Обрати внимание: если перемножать float64 и int напрямую, Go выдаст ошибку —
// типы нужно привести друг к другу явно через float64(count).
func totalPrice(pricePerOne float64, count int) float64 {
	return pricePerOne * float64(count)
}
```
В Go нельзя неявно смешивать `int` и `float64` в одном выражении: компилятор требует явного преобразования `float64(count)`.

## 4. Вывод в консоль (`fmt`)
Пакет `fmt` (от *format*) входит в стандартную библиотеку Go и отвечает за вывод текста.
- `fmt.Println(...)` — печатает значения и переносит строку.
- `fmt.Printf("шаблон", значения...)` — подставляет значения в шаблон с помощью спецификаторов:
  - `%s` — строка (`string`)
  - `%d` — целое число (`int`)
  - `%f` или `%.2f` — дробное число (`float64`), где `.2` означает «оставить 2 знака после запятой»
  - `%t` — булево значение (`bool`)
  - `\n` — перевод строки (в `Printf` он не ставится сам, в отличие от `Println`).

Пример:
```go
fmt.Printf("Напиток: %s, всего: %.2f руб.\n", drink, totalPrice(price, cups))
```
