# Теория к тикету 02: Условия (`if`, `switch`) и логические операторы

## 1. Ветвление `if / else if / else`
`if` позволяет программе выбирать разные действия в зависимости от условия.
В Go синтаксис максимально чистый:
- круглые скобки вокруг условия **не ставятся**;
- фигурные скобки `{ }` **обязательны** даже для одной строки;
- открывающая `{` всегда на той же строке, что и `if`.

```go
temp := -5

if temp < 0 {
	fmt.Println("Холодно, надеваем куртку")
} else if temp < 15 {
	fmt.Println("Прохладно, нужна ветровка")
} else {
	fmt.Println("Тепло")
}
```
Внутри `if` часто применяют **ранний возврат (early return)**: если данные некорректны, мы сразу выходим из функции с `return`, не усложняя остальной код вложенными `else`.

## 2. Логические операторы (`&&`, `||`, `!`)
Когда нужно объединить несколько проверок или инвертировать условие:
- `&&` (логическое И) — истина, только если **оба** условия верны (`age >= 18 && hasTicket`).
- `||` (логическое ИЛИ) — истина, если верно **хотя бы одно** условие (`day == "Sat" || day == "Sun"`).
- `!` (логическое НЕ) — переворачивает `bool` на противоположный (`!isBlocked` означает «не заблокирован»).

## 3. Оператор выбора `switch`
Когда нужно сравнить одно значение с несколькими конкретными вариантами (например, тип тарифа, валюту или день недели), вместо длинной цепочки `if / else if` в Go используют `switch`.

*Аналогия:* `switch` — это как распределитель писем по ячейкам: если письмо подходит под ячейку `"Moscow"`, оно идёт туда и на этом всё заканчивается.

Важное отличие от C/Java/JS: в Go после срабатывания `case` **не нужно писать `break`** — выполнение автоматически выходит из `switch`.
```go
grade := "A"

switch grade {
case "A":
	fmt.Println("Отлично")
case "B", "C": // можно перечислить несколько значений через запятую
	fmt.Println("Хорошо")
default:
	fmt.Println("Неизвестная оценка")
}
```
Ветка `default` срабатывает, если не подошёл ни один `case`.
Также в Go бывает `switch` без выражения после слова `switch` — тогда в каждом `case` можно писать любые булевы условия (как в красивом `if / else if`).
