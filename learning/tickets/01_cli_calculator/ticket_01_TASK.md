# Тикет 01: Инициализация `subtracker` и первый расчёт подписки

## Контекст
Мы начинаем разработку **subtracker** — консольного, а в будущем веб-сервиса для учёта регулярных подписок. Прежде чем хранить списки подписок в базе данных и отправлять уведомления в Telegram, нужно заложить фундамент проекта: создать Go-модуль и научить программу считать годовую стоимость одной подписки.

## Что нужно сделать
1. В корне репозитория создай папку `subtracker/` и инициализируй внутри неё Go-модуль с именем `subtracker` (команда `go mod init subtracker`).
2. Создай файл `main.go` в пакете `main` с точкой входа `func main()`.
3. Вынеси расчёт стоимости в отдельную функцию (например, расчёт суммы за заданное количество месяцев по ежемесячной цене):
   - функция должна принимать цену в месяц (`float64`) и количество месяцев (`int`), а возвращать итоговую стоимость (`float64`);
   - не забудь про явное приведение типов между `int` и `float64`.
4. Внутри `main()` объяви данные одной тестовой подписки с помощью переменных разных базовых типов:
   - название сервиса (`string`, например `"Яндекс Плюс"`),
   - цена за месяц (`float64`, например `399.0` или `299.5`),
   - количество месяцев оплаты (`int`, например `12`),
   - статус активности (`bool`, например `true`).
5. Вызови свою функцию расчёта и выведи в консоль понятную сводку по подписке с помощью `fmt.Printf` (цена должна отображаться аккуратно — с двумя знаками после запятой).

## Критерии приёмки (Definition of Done)
- [ ] Код находится строго внутри `subtracker/` (`go.mod` и `main.go`), без учебных файлов внутри этой папки.
- [ ] Команда `go run .`, запущенная из папки `subtracker/`, завершается без ошибок и печатает название подписки, статус активности, цену за месяц и рассчитанную стоимость за год (или за выбранное число месяцев) с двумя знаками после запятой.
- [ ] Команда `go build` собирает исполняемый файл без ошибок (собранный бинарник потом можно удалить, чтобы не засорять репозиторий).
- [ ] В коде нет неиспользуемых переменных, расчёт вынесен в отдельную функцию с понятным названием.
